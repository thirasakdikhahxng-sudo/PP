# Changelog

## 6.0.0 — Custom Edition
- ปรับธีม UI เป็น Forest Green / Ivory / Brass พร้อม responsive navigation, forms, cards, tables และ booking controls
- เพิ่มการจัดการบัญชีพนักงานและสิทธิ์แยกจากสิทธิ์ผู้ดูแลระบบ
- เพิ่มพื้นที่พนักงานสำหรับรับออเดอร์ จัดการครัว และรับชำระเงินสดตามสิทธิ์
- เพิ่มการรับชำระค่าจองด้วยเงินสดจากแอดมิน/พนักงาน พร้อมใบเสร็จและประวัติ
- เพิ่มการติดตามการคืนเงินสำหรับรายการรับเงินสด
- รวมยอดเงินสดเข้ารายงาน ยอดขาย และข้อมูลยอดใช้จ่ายลูกค้า
- ปิดการเปิดเผยสถานะ mock payment ผ่าน `/api/me` และคง endpoint จำลองไว้เฉพาะแอดมินในโหมด mock
- ป้องกันรายการชำระค่าอาหาร pending ซ้ำ/ยอดค้างเก่าด้วยการตรวจยอดและวิธีชำระก่อน reuse
- เพิ่ม schema migration แบบไม่ลบข้อมูลเดิม และเก็บฐานข้อมูลเดิมจากไฟล์ RAR ไว้ใน `data/booking.db`
